A shadcn grid is a responsive layout built with shadcn/ui primitives. The Gridcn ships Tron UI panels, bento blocks, and dashboard grids you can install into that stack.

## What you get

- Dashboard and analytics templates with metric grids
- Landing feature grids and HUD panels
- Components that drop into a standard shadcn/ui project
- Greek-god color themes without rewriting your tokens

## Install

Start with the [install guide](/docs/install), then pull the grid and panel components from the registry. For a full-page example, open the [dashboard template](/templates/dashboard) or the [landing template](/templates/landing).

## When to use The Gridcn

Use The Gridcn when you want a Tron UI look on top of shadcn/ui and a ready grid for dashboards or marketing pages. Stay on shadcn/ui alone when you only need unstyled primitives.
